Descripción General

Se realizó la instalación de Ubuntu, una distribución de Linux de código abierto, dentro de una máquina virtual usando Oracle VM VirtualBox. Este proyecto introdujo al estudiante en el mundo de los sistemas operativos alternativos a Windows, en la virtualización de sistemas y en el uso básico de la terminal de Linux.

La virtualización es una tecnología fundamental en la ingeniería de sistemas moderna, ya que permite ejecutar múltiples sistemas operativos en un mismo equipo físico, lo cual es ampliamente utilizado en servidores, desarrollo de software, pruebas de seguridad y entornos de aprendizaje.

¿Qué es Ubuntu?

Característica Descripción
Sistema operativo Ubuntu es una distribución de GNU/Linux basada en Debian. Es de código abierto y gratuita.
Versión utilizada Ubuntu 24.04.4 LTS (Long Term Support) — con soporte hasta 2029.
Arquitectura AMD64 de 64 bits.
Entorno de escritorio GNOME (interfaz gráfica moderna e intuitiva).
Tamaño de la imagen ISO Aproximadamente 5.7 GB.
Uso principal Servidores, desarrollo de software, educación, uso personal avanzado.

¿Qué es VirtualBox?

Oracle VM VirtualBox es un software de virtualización de código abierto que permite crear y ejecutar máquinas virtuales (VMs) en un equipo físico (llamado host). Cada máquina virtual actúa como una computadora independiente con su propio sistema operativo, procesador virtual, memoria RAM asignada y disco duro virtual.

Versión Utilizada Oracle VM VirtualBox 7.0.20
Sistema host Windows (PC del estudiante)
Sistema guest (invitado) Ubuntu 24.04 LTS

Proceso de Instalación Paso a Paso

Fase 1: Preparación

  1. Descarga de VirtualBox: Se accedió al sitio oficial de Oracle VirtualBox y se descargó el instalador para Windows (VirtualBox 7.0.20 platform packages — Windows hosts).
  2. Instalación de VirtualBox: Se ejecutó el instalador y se siguió el asistente de configuración. El proceso incluyó actualización del registro de componentes del sistema.
  3. Descarga de la imagen ISO de Ubuntu: Se accedió al sitio oficial de Ubuntu (ubuntu.com) y se descargó la imagen ISO de Ubuntu 24.04.4 LTS para arquitectura AMD64.

Fase 2: Creación de la Máquina Virtual

  1. Abrir VirtualBox y hacer clic en "Nueva".
  2. Asignar nombre a la VM: "Ubuntu 24".
  3. Seleccionar el tipo: Linux, versión: Ubuntu (64-bit).
  4. Asignar memoria RAM: mínimo 2048 MB (2 GB), recomendado 4096 MB (4 GB).
  5. Crear un disco duro virtual: archivo VDI de 25 GB o más, asignación dinámica.
  6. En "Almacenamiento", cargar la imagen ISO de Ubuntu en la unidad óptica virtual.

Fase 3: Instalación de Ubuntu

  1. Iniciar la máquina virtual. El sistema arrancará desde la ISO de Ubuntu.
  2. Seleccionar idioma: Español.
  3. Elegir "Instalar Ubuntu" (no "Probar sin instalar").
  4. Seleccionar tipo de instalación: "Normal" (incluye aplicaciones esenciales).
  5. Elegir "Borrar disco e instalar Ubuntu" (en el disco virtual, no afecta el host).
  6. Configurar zona horaria: Ciudad de Guatemala.
  7. Crear usuario: nombre, nombre del equipo y contraseña.
  8. Iniciar la instalación. El proceso tarda aproximadamente 15-30 minutos.
  9. Al finalizar, reiniciar la VM y retirar la ISO del lector virtual.

Fase 4: Configuración Posterior a la Instalación

  1. Actualizar el sistema: abrir terminal y ejecutar sudo apt update && sudo apt upgrade.
  2. Instalar paquetes adicionales según necesidad (en el proyecto se instaló tree y zip).
  3. Explorar el entorno gráfico GNOME y las aplicaciones preinstaladas.
  4. Practicar comandos básicos de terminal (ls, cd, mkdir, rm, sudo, apt, etc.).

Comandos de Terminal Practicados

Comando Descripción
sudo apt update Actualiza la lista de paquetes disponibles desde los repositorios.
sudo apt upgrade Instala las actualizaciones de los paquetes ya instalados.
sudo apt install [paquete] Instala un paquete de software específico.
ls Lista los archivos y directorios del directorio actual.
cd [directorio] Cambia al directorio especificado.
mkdir [nombre] Crea un nuevo directorio.
pwd Muestra la ruta del directorio actual.
sudo Ejecuta un comando con permisos de administrador (superusuario).

Diferencias entre Windows y Ubuntu

Característica Windows Ubuntu (Linux)
Costo De pago (licencia) Gratuito y de código abierto
Gestión de software Instaladores .exe, Microsoft Store Gestor de paquetes APT, Snap
Terminal CMD / PowerShell (uso limitado) Bash / Terminal (uso extenso)
Uso en servidores Windows Server (de pago) Dominante en servidores mundiales
Personalización Limitada Muy alta (código abierto)
Seguridad Mayor superficie de ataque Generalmente más seguro

Competencias Adquiridas

  • Instalación y configuración básica de software: Instalar un sistema operativo completo desde cero y configurar sus parámetros iniciales.
  • Manejo de virtualización: Comprender el concepto de máquinas virtuales y saber configurarlas con recursos apropiados.
  • Uso de la terminal de Linux: Ejecutar comandos básicos en Bash, entender el sistema de permisos y gestionar paquetes con APT.
  • Conocimiento de sistemas operativos alternativos: Familiarizarse con el ecosistema Linux, fundamental en servidores y desarrollo profesional.
