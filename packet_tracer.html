Descripción General del Proyecto

En este proyecto se diseñó e implementó una red LAN (Local Area Network) dentro de una vivienda de tres niveles, utilizando el simulador Cisco Packet Tracer. El objetivo principal fue aplicar conocimientos teóricos y prácticos sobre redes, incluyendo direccionamiento IP, conexión de dispositivos, seguridad mediante contraseñas y pruebas de conectividad entre todos los dispositivos de la red.

La red permite que todos los dispositivos distribuidos en los tres niveles del hogar puedan comunicarse entre sí, compartir recursos (como una impresora) y mantener conectividad tanto cableada como inalámbrica.

Tipo de Red y Topología

  • Tipo de red: LAN — Local Area Network
  • Topología: Híbrida (estrella extendida)
  • Explicación de la topología: Se considera estrella porque todos los dispositivos dependen de un punto central (router/switch), y extendida porque la red se distribuye en varios niveles mediante cascada entre dispositivos de red.

Direccionamiento IP

Clase de redClase B
Red base172.16.0.0
Máscara de subred255.255.0.0
Razón de elecciónLa clase B permite una mayor cantidad de hosts dentro de una red, siendo ideal para este tipo de implementación con múltiples dispositivos.

Dispositivos de Red Utilizados

Dispositivo Función en la red
Router inalámbrico (WRT300N) Dispositivo principal que asigna direcciones IP y permite la conexión entre la red interna e internet. También provee señal WiFi al primer nivel.
Switch (2960-24TT) Interconecta todos los dispositivos cableados del segundo nivel y sirve de punto central de distribución para toda la red.
Access Point (AccessPoint0) Amplía la señal inalámbrica hacia el tercer nivel del hogar, permitiendo la conexión de tablets y laptops sin cable.

Descripción de la Topología por Nivel

Primer Nivel — Planta Baja

  • 1 Router inalámbrico (WRT300N — Wireless Router0)
  • 2 computadoras de escritorio conectadas al router (PC0 y PC10 / PC3 y PC4)
  • 1 impresora conectada directamente al router (Printer0)
  • Conexión: cable directo entre PCs, impresora y el router

Segundo Nivel

  • 1 Switch central (2960-24TT — Switch0)
  • 3 computadoras de escritorio (PC2, PC5, PC6)
  • 3 laptops conectadas por cable (Laptop0, Laptop1, Laptop2)
  • El Switch se conecta al Router del primer nivel mediante cable directo
  • El Access Point del tercer nivel también se conecta al Switch

Tercer Nivel

  • 1 Access Point inalámbrico (AccessPoint0)
  • 3 tablets conectadas de forma inalámbrica (Tablet PC0, Tablet PC1, Tablet PC02)
  • 3 laptops conectadas de forma inalámbrica (Laptop3, Laptop4, Laptop5)

Pruebas de Conectividad

Método: Comando "ping" desde consola

Se utilizó el comando ping dentro de Packet Tracer para verificar la comunicación entre dispositivos. Si los paquetes se envían y reciben correctamente, significa que hay conectividad exitosa entre los nodos de la red.

Resultados Esperados y Obtenidos

Se logró una red completamente funcional donde todos los dispositivos de los tres niveles del hogar pueden:

  • Comunicarse entre sí mediante ping exitoso.
  • Compartir recursos como la impresora del primer nivel.
  • Mantener seguridad mediante contraseñas en el router y el access point.
  • Conectarse tanto por cable (PCs y laptops del nivel 2) como de forma inalámbrica (tablets y laptops del nivel 3).

Conceptos Clave Aplicados

ConceptoDescripción
Red LANConjunto de dispositivos conectados dentro de un área geográfica limitada (el hogar).
RouterDispositivo principal que asigna direcciones IP y permite la conexión entre redes.
SwitchInterconecta múltiples dispositivos dentro de una misma red local.

Competencias Adquiridas

  • Diseño y simulación de redes LAN con múltiples dispositivos y niveles.
  • Configuración de routers, switches y access points en Packet Tracer.
  • Aplicación de direccionamiento IP Clase B y configuración de máscaras de subred.
  • Realización de pruebas de conectividad mediante comandos de consola.
  • Comprensión de topologías de red y su aplicación en entornos reales del hogar.
  • Configuración de seguridad básica mediante contraseñas en dispositivos inalámbricos.
