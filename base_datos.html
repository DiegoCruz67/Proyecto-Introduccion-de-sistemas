Descripción General del Proyecto

Se diseñaron e implementaron dos bases de datos relacionales desde cero, utilizando MySQL Workbench para el modelado entidad-relación y phpMyAdmin para la ejecución y gestión de los datos. El proyecto implicó identificar entidades, definir atributos, establecer claves primarias y foráneas, y poblar las tablas con registros de prueba.

Las dos bases de datos desarrolladas fueron: un Sistema de Biblioteca (gestión de libros, usuarios y préstamos) y una Red Social (gestión de usuarios, publicaciones, grupos e interacciones).

Base de Datos 1: Sistema de Biblioteca

Descripción

El sistema permite gestionar el préstamo de libros a usuarios registrados. Contiene tres entidades principales relacionadas entre sí mediante claves foráneas. Se diseñó el diagrama entidad-relación en MySQL Workbench y luego se implementó mediante Forward Engineering para generar el script SQL automáticamente.

Tabla: prestamo

CampoTipoDescripción

Relaciones entre tablas — Biblioteca

  • usuarios → prestamo: Un usuario puede tener múltiples préstamos (1 a muchos). La tabla prestamo contiene idUsuario como clave foránea.
  • libro → prestamo: Un libro puede aparecer en múltiples préstamos (1 a muchos). La tabla prestamo contiene idLibro como clave foránea.
  • Las restricciones de integridad referencial son ON DELETE RESTRICT / ON UPDATE RESTRICT.

Base de Datos 2: Red Social

Descripción

El sistema simula una red social básica donde los usuarios pueden publicar contenido, interactuar con publicaciones de otros (likes, comentarios, reposts) y pertenecer a grupos temáticos. Se implementaron múltiples tablas con relaciones entre ellas para reflejar la complejidad de una red social real.

Proceso de Implementación

  1. Diseño del diagrama entidad-relación (ERD) en MySQL Workbench.
  2. Definición de tablas, atributos, tipos de datos y restricciones.
  3. Establecimiento de relaciones y claves foráneas entre tablas.
  4. Generación del script SQL mediante Forward Engineering de Workbench.
  5. Ejecución del script en el servidor local mediante phpMyAdmin (XAMPP).
  6. Inserción de datos de prueba en todas las tablas.
  7. Verificación de los datos con consultas SELECT * FROM [tabla].

Consultas SQL utilizadas

-- Crear base de datos
CREATE SCHEMA IF NOT EXISTS `biblioteca` DEFAULT CHARACTER SET utf8;
USE `biblioteca`;

-- Ver todos los usuarios
SELECT * FROM `usuarios`;

-- Ver todos los libros
SELECT * FROM `libro`;

-- Ver todos los préstamos
SELECT * FROM `prestamo`;

-- Ver todas las interacciones de la red social
SELECT * FROM `interaccion`;

Competencias Adquiridas

  • Diseño de diagramas entidad-relación (ERD) para sistemas de información reales.
  • Definición correcta de claves primarias y foráneas para mantener integridad referencial.
  • Uso de MySQL Workbench para modelado visual de bases de datos.
  • Generación y ejecución de scripts SQL mediante Forward Engineering.
  • Gestión y consulta de datos con phpMyAdmin.
  • Inserción, consulta y verificación de datos en tablas relacionales.
  • Comprensión de relaciones uno a muchos entre entidades.
